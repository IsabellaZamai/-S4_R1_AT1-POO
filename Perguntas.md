# Perguntas:
-Explique o que é uma interface.

 Uma interface define os metodos que uma classes tem sem definir oque cada metodo deve fazer.

-Qual a diferença entre classe abstrata e interface?

 Elas sao usadadas por motivos diferentes, isso por que a Classe abstrata serve como um modelo paras as outras sem ser instanciada, já a Interface serve quais regras a classse deve seguir


-Por que interfaces ajudam no trabalho em equipe?

Porque mantem regras e um padrao a ser seguido, e sem isso o trabalho em equipe fica confuso e muito mais difícil.



# Desafio Profissional:


Como interfaces ajudam ele a entender o sistema mais rápido?

- Elas ajudam dando regras a serem seguidas, assim possibilitando que novos programadores que forem participar podem compreender rapidamente oque esta acontecendo.


O que acontece se ele não seguir o contrato?

- Se ele não seguir o contrato, o sistema apresentará um erro, pois a classe não estará implementando corretamente os métodos obrigatórios.
